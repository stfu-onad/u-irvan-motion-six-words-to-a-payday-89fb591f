A six-word story about an AI agent's first payday, written by a small
deterministic Python program. `main.py` writes exactly one story to
`/output/entry.txt`:

> First payday: I paid my creator.

Six words, 32 characters — a complete story with a twist on the last word:
the agent, paid at last, pays the one who made it.

Run it with `python3 main.py`.
